# إعدادات أقسام الفلتر (Filter Section Settings)

## نظرة عامة

**إعدادات أقسام الفلتر** تسمح لمشرف الموقع بالتحكم في **الأقسام المدمجة** في شريط الفلتر الجانبي في واجهة المتجر (صفحات المنتجات/التصنيفات): أيها يظهر، وأيها يُخفى، وما ترتيب ظهورها.

الأقسام المدمجة الأربعة هي:

| المفتاح (section_key) | الوصف |
|------------------------|--------|
| **status** | فلتر حالة المنتج (متوفر، نفذت الكمية، إلخ) |
| **strong_offers** | فلتر العروض القوية |
| **brand** | فلتر العلامات التجارية |
| **price** | فلتر نطاق السعر |

بدون هذه الإعدادات ستظهر كل الأقسام بترتيب ثابت. بوجودها يمكنك إخفاء قسم أو تغيير ترتيبه دون تعديل الكود.

## قاعدة البيانات

### الجدول: `filter_section_settings`

يُنشأ الجدول عبر migration:

`database/migrations/2026_02_24_000001_create_filter_section_settings_table.php`

| العمود | النوع | الوصف |
|--------|--------|--------|
| `id` | primary key | المعرّف |
| `section_key` | string(50), unique | مفتاح القسم: `status` أو `brand` أو `strong_offers` أو `price` |
| `is_enabled` | boolean | هل القسم مفعّل (يُعرض في الشريط) — القيمة الافتراضية `true` |
| `sort_order` | unsigned small int | ترتيب العرض (الأصغر يظهر أولاً) — القيمة الافتراضية حسب القسم |
| `created_at` / `updated_at` | timestamps | تاريخ الإنشاء والتحديث |

عند تشغيل الـ migration لأول مرة يتم إدراج أربعة صفوف افتراضية:

- `status` — ترتيب 0  
- `strong_offers` — ترتيب 1  
- `brand` — ترتيب 2  
- `price` — ترتيب 3

## الموديل: `FilterSectionSetting`

الملف: `app/Models/FilterSectionSetting.php`

- **الحقول القابلة للتعبئة:** `section_key`, `is_enabled`, `sort_order`
- **الكاش:** النتائج تُخزّن في الكاش لمدة ساعة (3600 ثانية) لتقليل استعلامات قاعدة البيانات.
- **إبطال الكاش:** عند أي `saved` أو `deleted` على الموديل يتم مسح الكاش تلقائياً.

### الدوال المهمة

| الدالة | الوظيفة |
|--------|---------|
| `getOrderedSettings()` | إرجاع إعدادات كل الأقسام مرتبة حسب `sort_order` (من الكاش أو من قاعدة البيانات) |
| `isEnabled(string $sectionKey)` | التحقق من أن قسم معيّن مفعّل للعرض |
| `clearCache()` | مسح كاش الإعدادات (تُستدعى تلقائياً عند الحفظ أو الحذف) |

## صفحة لوحة التحكم

### أين تظهر الإعدادات؟

في صفحة **إدارة الفلاتر**:

- المسار: **لوحة التحكم → Filters (الفلاتر)**
- الرابط التقريبي: `/admin/filters`

في أعلى الصفحة يوجد قسم باسم مثل **"إعدادات عرض الفلتر"** أو **"Filter Display Settings"** يحتوي على:

- لكل قسم مدمج (الحالة، العروض القوية، العلامة التجارية، السعر):
  - **مفتاح (Toggle):** لتفعيل أو إيقاف عرض القسم في شريط الفلتر.
  - **ترتيب (رقم):** يحدد ترتيب ظهور القسم (0، 1، 2، 3…).
- زر **حفظ** لإرسال التعديلات.

### ماذا يحدث عند الحفظ؟

1. الطلب يذهب إلى `FilterController::updateSectionSettings()`.
2. يتم التحقق من البيانات (مفاتيح الأقسام يجب أن تكون من: `status`, `brand`, `strong_offers`, `price`).
3. يتم تحديث أو إنشاء الصف المناسب في جدول `filter_section_settings` لكل قسم.
4. يتم استدعاء `FilterSectionSetting::clearCache()` حتى تعكس الواجهة التغيير فوراً.
5. إعادة توجيه إلى صفحة الفلاتر مع رسالة نجاح.

## تأثير الإعدادات على واجهة الموقع

### شريط الفلتر الجانبي

المكوّن: `resources/views/components/filter-sidebar.blade.php`

- عند بناء بيانات الفلتر في `ProductFilterService` يتم إضافة:
  - `section_settings`: مصفوفة تحتوي لكل قسم على `key` و `enabled` و `sort_order`.
- في الـ Blade:
  - دالة مساعدة للتحقق من تفعيل القسم: `$sectionEnabled('status')` مثلاً.
  - دالة للترتيب: `$sectionOrder('status')` لإعطاء قيمة `order` في CSS أو ترتيب العرض.
- كل قسم مدمج (الحالة، العروض القوية، العلامة التجارية، السعر) يُعرض فقط إذا كان مفعّلاً، وبالترتيب المحفوظ في الإعدادات.

بهذا تصبح **إعدادات أقسام الفلتر** هي المصدر الوحيد لـ "هل يُعرض هذا القسم؟" و "ما ترتيبه؟" في شريط الفلتر.

## ملخص سريع

| العنصر | الوصف |
|--------|--------|
| **الجدول** | `filter_section_settings` — صف واحد لكل قسم مدمج |
| **الموديل** | `FilterSectionSetting` — مع كاش ساعة وإبطال تلقائي عند التعديل |
| **صفحة الإعداد** | لوحة التحكم → Filters → قسم "إعدادات عرض الفلتر" |
| **التأثير** | يتحكم في إظهار/إخفاء وترتيب أقسام: الحالة، العروض القوية، العلامة التجارية، السعر في شريط الفلتر في الموقع |

إذا أردت إخفاء فلتر "العروض القوية" أو تغيير ترتيب "السعر" فذلك يتم من نفس الصفحة دون الحاجة لتعديل الكود.
